# GHP-WEB
PAGINA WEB DE GHP

## Preparado para despliegue con dominio personalizado

Esta web está preparada como sitio estático para publicarse en hosting de dominio personalizado como www.ghpartners.es.

### Archivos clave
- index.html: página principal
- styles.css: estilos visuales
- script.js: interacciones
- CNAME: apunta el dominio personalizado a la publicación
- robots.txt: SEO básico
- sitemap.xml: mapa del sitio

### Configuración recomendada
1. Publica este repositorio en GitHub.
2. En la configuración del repositorio, activa GitHub Pages.
3. Usa el dominio personalizado www.ghpartners.es.
4. En el registro DNS del dominio, crea un registro CNAME o A según el hosting.
5. Si usas GitHub Pages, deja el archivo CNAME con el contenido:
   www.ghpartners.es

### Revisión
La vista local funciona en http://localhost:8000.

### Siguiente paso
Cuando el dominio esté apuntado y el hosting esté activo, la web quedará disponible en la URL real.
